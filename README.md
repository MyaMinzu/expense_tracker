# expense_tracker
My Expense Tracker
A beginner-friendly expense tracker built with Python.
Features
• Add expenses with date, item name, category, and price
• View all recorded expenses
• Calculate total spending
• Set a monthly budget
• Check remaining budget
• Save expenses to a text file
• Keep saved expenses when the program is restarted
Technologies Used
• Python
• Lists
• Loops
• If/else statements
• File handling
How to Run
1. Install Python.
2. Download zuzuexpenseTracker.py from this repository.
3. Open a terminal in the folder containing the file.
4. Run:
python zuzuexpenseTracker.py
Project Purpose
This is my first Python project. I built it to practise Python fundamentals, manage expenses, and improve my programming skills.
